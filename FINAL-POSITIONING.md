# Relay — Final Hackathon Positioning

## One-line pitch

**Relay is a durable Alexa+ task-execution layer that preserves user intent across context, approvals, failures and time.**

## Flagship experience

**Relay HomeOps** transforms:

```text
"My AC isn't cooling."
```

into:

```text
owned-product context
→ warranty check
→ safe troubleshooting
→ bounded service contract
→ provider search
→ human approval
→ failure recovery
→ durable resume
→ decision receipt
```

## Why not pivot to CartSync?

CartSync, Wardrobe Concierge, Event Planning, Moving and Kitchen agents are useful verticals, but each would create a second product.

Relay is more differentiated as the reusable durable execution architecture underneath those experiences.

Use those ideas in **What's Next**, not as competing core demos.

## Core differentiation

Alexa+ manages the conversation.

Relay handles what conversation continuity alone does not solve:

- durable external task state
- explicit constraints
- irreversible-action boundaries
- failure compensation
- scheduled continuation
- cross-session auditability

## Future domains

The same Relay primitives can later power:

- commerce bundle execution
- warranty/receipt lifecycle management
- event coordination
- relocation orchestration
- grocery replenishment
- travel planning
